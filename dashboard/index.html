Overview

Backtest pipeline for a single locked risk signal on SPY. Python computes every metric; this site only displays exported results from dashboard_data.json.

Before any result is treated as usable, the signal must beat a null model: random flags on the same number of days, 1,000 Monte Carlo runs, real precision above the null 95th percentile, lift ≥ 1.5. Deviations from the locked spec require a note in /decisions/.

Pipeline

data_loader.py → backtest.py → metrics.py / null_gate.py → export_dashboard_data.py → dashboard.

Prices come from Yahoo Finance (split- and dividend-adjusted). The backtest classifies each trading day; uncertainty ranges use a paired circular block bootstrap (see track record footnote).

V1 signal

Universe: SPY daily closes, 2000-01-01 through export date. Flag on day t when 20-day realized vol exceeds 1.5× its trailing 252-day median. Outcome: ≥5% drawdown within the next 30 trading days (min(closet+1..t+30) / closet − 1 ≤ −0.05). 

ret_t      = log(close_t / close_{t-1})
vol_20_t   = std(ret_{t-19..t}) * sqrt(252)
flag_t     = 1 if vol_20_t > 1.5 * median(vol_20_{t-251..t})
